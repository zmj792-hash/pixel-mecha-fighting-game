# 像素机甲对战 v1.0

## 🎮 产品说明

复古 16 位像素风格的本地对战格斗小游戏。两位玩家（或人机）各操控一台像素机甲，在科幻竞技场中通过移动、攻击、防御与特殊技能进行对决，三局两胜决定最终胜负。

## 🎯 操作方式

| 操作 | P1 赤焰机甲 | P2 苍蓝机甲 |
|------|------------|------------|
| 移动 | A / D | ← / → |
| 跳跃 | W | ↑ |
| 防御 | S（按住） | ↓（按住） |
| 轻攻击 | F | J |
| 重攻击 | G | K |
| 必杀技 | H（能量≥50） | L（能量≥50） |

## 📋 功能清单

- ✅ 开始界面：标题霓虹辉光动画、模式选择（双人/AI）、操作说明
- ✅ 对战界面：赛博朋克竞技场、HUD（血条/能量条/回合比分/倒计时）
- ✅ 战斗系统：移动/跳跃/轻攻击/重攻击/防御/必杀技
- ✅ 能量系统：攻击积攒能量，≥50可释放必杀技（25伤害）
- ✅ 回合系统：三局两胜、60秒倒计时、超时血量判定、回合过场动画
- ✅ AI 对手：具备反应延迟、防御倾向、距离判断的智能AI
- ✅ 结算界面：胜方特写、VICTORY展示、重新开始/返回菜单
- ✅ CRT 后处理：扫描线叠加、暗角效果、屏幕震动、命中闪屏
- ✅ 像素精灵：32×40 机甲，含待机/行走/攻击/防御/受击/KO帧
- ✅ 特效系统：命中火花、伤害数字、防御护盾光圈

直接用浏览器打开 `index.html` 即可。
